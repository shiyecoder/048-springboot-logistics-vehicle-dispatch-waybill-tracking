# 组件规范 · 运联通 TMS（NEW-048）

> 与 `design/design-system.md` 配套。前端实现位于 `frontend/src/components/`，类名与尺寸按本文件执行。

## 1. 按钮 Button

| 类型 | 类名 | 高 | 内边距 | 说明 |
|---|---|---|---|---|
| 主按钮 | `.btn.p` | 32px | 0 14px | 底色 `#5B2533`，白字，hover `#4A1D2A` |
| 次按钮 | `.btn.a` | 32px | 0 14px | 底色 `#2F6F6A`，白字 |
| 默认按钮 | `.btn` | 32px | 0 14px | 白底 + `#E7DFDC` 描边 |
| 危险按钮 | `.btn.d` | 32px | 0 14px | 白底 + `#E4C4C7` 描边 + `#A61B29` 字 |
| 小按钮 | `.btn.sm` | 26px | 0 9px | 表格行内操作 |

- 字号 12px，圆角 5px，图标与文字间距 6px。
- 移动端主按钮高度 ≥ 44px。
- 同一操作区按钮不超过 3 个，主操作在最右。

## 2. 输入与选择

| 组件 | 高 | 宽度 | 备注 |
|---|---|---|---|
| 文本框 `.inp` | 32px | 170–230px（搜索项） | 圆角 5px，聚焦描边 `#5B2533` |
| 下拉框 `.sel` | 32px | **180–240px** | 搜索条件下拉统一 180px 起，禁止占满整行 |
| 日期 / 日期范围 | 32px | 230–280px | 使用日期组件，不用文本框 |
| 文本域 | ≥64px | 100% | 内边距 8×10px |
| 数字输入 | 32px | 100–140px | 带单位后缀（吨 / m³ / km / 元） |

- 表单标签右对齐、宽 100–120px，必填项标签后加红色 `*`。
- 校验失败：输入框描边 `#A61B29`，下方 11.5px 红字提示。

## 3. 表格 Table

- 表头：底 `#FBF7F5`，字 `#6B5E62` 12px/600，**不写死列宽**，`white-space:nowrap` + 最小宽度自适应，超出横向滚动。
- 行高：内容行 10px 上下内边距（约 44px 行高），hover 底色 `#FDFAF8`。
- 编号列、状态列、日期列、操作列强制单行。
- 分页：右侧对齐，页码 26×26px，当前页主色实底；每页条数 10/20/50 可切，切换筛选条件页码回 1。
- 移动端 <768px 表格改为信息卡片（编号 / 状态 / 时间 / 负责人），点击进详情。

## 4. 状态标签 Tag

| 语义 | 类 | 颜色 | 示例 |
|---|---|---|---|
| 成功 | `.tag.ok` | `#2D765C` / 底 `#F1F8F4` / 边 `#BFDCCF` | 已签收、已审核、可用 |
| 进行中 | `.tag.run` | `#2F6F6A` / 底 `#F1F7F6` / 边 `#BFD8D5` | 运输中、处理中 |
| 警告 | `.tag.warn` | `#B4761E` / 底 `#FCF6EA` / 边 `#E8D3AE` | 待调度、即将到期 |
| 危险 | `.tag.bad` | `#A61B29` / 底 `#FBF1F2` / 边 `#E4C4C7` | 异常、已驳回、超时 |
| 中性 | `.tag.gray` | `#6B5E62` / 底 `#F7F4F2` / 边 `#E7DFDC` | 已作废、草稿 |

高度 22px，字号 11.5px，圆角 4px，1px 描边，左侧可选 5px 圆点。**必须带中文文字**，不能只靠颜色。

## 5. 卡片 Card

- 白底 + 1px `#E7DFDC` + 圆角 8px；标题区 14px/16px 内边距，底部 1px 分隔线；内容区 16px 内边距。
- 卡片标题右侧放操作（`card-h .sp` 撑开 + 右侧按钮或链接）。
- 卡片内不再套卡片，需要分区用 1px 分隔线或浅底区块。

## 6. 弹窗与抽屉

| 类型 | 宽度 | 用途 |
|---|---|---|
| 抽屉 Drawer | 520px（表单）/ 680px（详情+操作） | 配车、流转、审批、复核 —— 主流程一律用抽屉 |
| 弹窗 Dialog | 420px | 二次确认、原因填写（退回/驳回/作废） |

- 抽屉从右侧滑入，顶部固定标题 + 单据摘要（编号、客户、状态），底部固定操作条。
- 关闭前检测未保存内容，提示「有未保存的修改，确认离开？」。
- 二次确认文案必须写清后果与影响对象，例如「确认退回回单 HD20261031004？退回后运单将回到『到达签收』阶段」。

## 7. 分页 Pager

- 结构：`共 N 条` + 上一页 + 页码（最多 7 个）+ 下一页 + `每页条数`。
- 固定右下；不与底部固定操作条重叠（移动端留 64px 安全区）。
