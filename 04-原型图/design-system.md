# 设计系统 · 运联通 TMS（NEW-048）

> 依据需求文档「UI 视觉与交互设计」一节的「文化绛红」方向落地，所有色值、圆角、字号与间距在本文件定义，
> `design/pages/*.html` 与前端 `src/styles.css` 必须与本文件一致，不允许各页面自行发明颜色。

## 1. 色彩

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--p` 主色 | `#5B2533` | 顶部栏、侧边栏、主按钮、当前菜单、关键数字 |
| `--p2` 主色深 | `#4A1D2A` | 主按钮 hover、按下态 |
| `--a` 辅助色 | `#2F6F6A` | 次级按钮、筛选选中态、普通图表系列 |
| `--acc` 强调色 | `#7A3947` | 链接、信息提示、图表对比系列 |
| `--bg` 页面背景 | `#FAF7F5` | 主内容区背景 |
| `--card` 容器 | `#FFFFFF` | 表格、表单、卡片容器 |
| `--line` 描边 | `#E7DFDC` | 1px 分隔线、输入框边框 |
| `--ink` 正文 | `#241A1D` | 正文、表格内容 |
| `--ink2` 次要文字 | `#6B5E62` | 标签、说明、占位 |
| `--ok` 成功 | `#2D765C` | 已完成、已通过、正常 |
| `--warn` 警告 | `#B4761E` | 即将超时、待确认、临期证件 |
| `--bad` 危险 | `#A61B29` | 驳回、超时、异常、删除确认（只做小面积） |

图表系列（同义同色，跨页面一致）：主色 `#5B2533` → 辅助 `#2F6F6A` → 强调 `#7A3947` → 暖黄 `#B4761E` → 中性灰 `#9C8A86` / `#C3B2AE`。

**状态不能只靠颜色**：任何状态色必须同时带中文标签（`已完成`、`待调度`…），标签用 1px 描边 + 浅底，不用实心色块。

## 2. 字体与数字

- 字体栈：`"PingFang SC","Hiragino Sans GB","Microsoft YaHei",system-ui,sans-serif`，不引入外网字体。
- 字号阶梯：页面标题 19px/600 · 卡片标题 14px/600 · 正文 13px · 表格 12.5px · 辅助说明 12px · 极小标注 11.5px。
- 行高 1.55；标题 letter-spacing 0.3–0.5px。
- **数字列**统一加 `.num`：`font-variant-numeric: tabular-nums`，金额、重量、里程、时间右对齐。
- 业务编号（运单号、调度单号）用等宽 `.mono`，颜色为 `--p`，可点击进详情。

## 3. 圆角 / 描边 / 阴影

| 元素 | 圆角 | 阴影 |
|---|---|---|
| 卡片、抽屉面板 | 8px | 常规无阴影 |
| 按钮、输入框、标签 | 5px | 无 |
| 缩略图 | 4px | 无 |
| 抽屉 / 弹窗 | 8px | 仅此处用阴影：`-12px 0 32px rgba(60,20,30,.12)` |

整体原则：**阴影只用于浮层**，平面卡片靠 1px `--line` 描边区分层级。禁止发光、渐变按钮、装饰性光效。

## 4. 布局栅格

- 后台：左侧菜单 220px（固定）+ 顶部栏 56px + 内容区自适应，内容区外边距 24px。
- 卡片间距 14px；卡片内边距 16px；表单行距 12px。
- 看板首屏：6 个 KPI（`repeat(6,1fr)` 12px 间距）+ 2 列图表区 + 3 列图表区，整体控制在 1440×900 一屏。
- 详情页：顶部状态条（编号 / 状态 / 责任人 / 创建时间 / 最近更新）+ 2 列信息区 + 时间轴与关联单据。
- 表单标签宽 100–120px（右对齐），输入宽度 360–520px；搜索下拉框 180–240px。
- 门户（客户/司机）：顶部 60px 白底导航 + 内容最大宽 1180px 居中。

## 5. 页面骨架差异

| 角色 | 骨架 | 视觉差异 |
|---|---|---|
| 车队经理 / 调度员 / 客服财务 | `AdminLayout`（绛红侧边栏 + 白顶栏） | 深色侧栏、密集表格、状态标签多 |
| 驾驶员 | `DriverLayout`（绛红顶部 + 单列任务卡） | 大按钮（44px）、任务卡、时间轴为主，移动优先 |
| 客户 / 货主 | `PortalLayout`（白底导航 + 绛红 hero） | 圆角大、留白多、进度条式 5 段状态 |

## 6. 交互规范

- 危险操作（退回、驳回、作废、删除、关闭异常）用红色描边按钮 + 二次确认；普通取消不使用强提醒。
- 行内最多「查看 + 2 个高频操作」，其余收进「更多」。
- 审批 / 流转用右侧抽屉，抽屉内展示单据摘要，避免来回切页。
- 列表加载 >300ms 显示表格 loading，禁止整页白屏；空状态说明原因 + 下一步（如「当前筛选条件下无记录，清空筛选或新建运单」）。
- 所有时间统一 `yyyy-MM-dd HH:mm:ss`，由 `utils/format.js` 的 `fmtTime` 统一格式化。
